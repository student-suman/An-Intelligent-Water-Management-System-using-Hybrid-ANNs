2. SETUP INSTRUCTIONS (PREPARATION)
================================================================================

STEP 1: Download All Project Files
-----------------------------------
Download these 5 files to a folder on your computer:

    ✓ data_generator.py
    ✓ model.py
    ✓ train.py
    ✓ predict.py
    ✓ requirements.txt

Put them all in the same folder, for example:
    C:\MyProjects\IrrigationAI\        (Windows)
    /Users/yourname/IrrigationAI/      (Mac)
    /home/yourname/IrrigationAI/       (Linux)


STEP 2: Open Terminal/Command Prompt
-------------------------------------
Windows:
    - Press Windows Key + R
    - Type: cmd
    - Press Enter

Mac:
    - Press Command + Space
    - Type: terminal
    - Press Enter

Linux:
    - Press Ctrl + Alt + T


STEP 3: Navigate to Your Project Folder
----------------------------------------
Use the 'cd' command to go to your project folder:

Windows:
    cd C:\MyProjects\IrrigationAI

Mac/Linux:
    cd /Users/yourname/IrrigationAI

TIP: You can drag and drop the folder into the terminal to auto-fill the path!


STEP 4: Install Required Libraries
-----------------------------------
Copy and paste this command exactly as shown:

    pip install tensorflow pandas numpy scikit-learn joblib

Press Enter and wait (this may take 2-5 minutes).

✅ SUCCESS: You'll see "Successfully installed..." messages
❌ ERROR: If you see errors, try this alternative:

    pip3 install tensorflow pandas numpy scikit-learn joblib

    OR (if permission denied):

    pip install --user tensorflow pandas numpy scikit-learn joblib


================================================================================
3. RUNNING THE PROJECT (COOKING STEPS)
================================================================================

NOW THE FUN PART! Follow these 3 steps in order:


📊 STEP 1: Generate Training Data
----------------------------------
Command:
    python data_generator.py

What happens:
    ✓ Creates a file called "irrigation_dataset.csv"
    ✓ Contains 1000 sample data points
    ✓ Shows you a preview of the data

Expected output:
    "Dataset generated successfully with 1000 samples!"
    [You'll see some sample data displayed]

⏱️ Time: 2-3 seconds


🧠 STEP 2: Train the AI Model
------------------------------
Command:
    python train.py

What happens:
    ✓ Loads the dataset
    ✓ Trains the neural network (50 epochs)
    ✓ Creates two files:
        - irrigation_model.keras (the trained AI brain)
        - scaler.pkl (data preprocessing settings)
    ✓ Shows training progress and final accuracy

Expected output:
    You'll see:
    - "TRAINING HYBRID ANN FOR IRRIGATION OPTIMIZATION"
    - Progress bars for each epoch (1/50, 2/50, ... 50/50)
    - "Test Mean Squared Error: ~16.xx"
    - "R² Score: ~0.93" (93% accuracy!)
    - "TRAINING COMPLETE!"

⏱️ Time: 30-60 seconds


🔮 STEP 3: Make Predictions
----------------------------
Command:
    python predict.py

What happens:
    ✓ Loads the trained model
    ✓ Runs 4 example predictions with different conditions
    ✓ Shows irrigation recommendations

Expected output:
    You'll see predictions for:
    
    [Example 1] Moderate conditions
        - Soil: 35%, Temp: 30°C, Humidity: 60%
        - PREDICTED: ~35 minutes
        - Recommendation: High irrigation needed
    
    [Example 2] High moisture, low temperature
        - Soil: 80%, Temp: 15°C, Humidity: 70%
        - PREDICTED: ~13 minutes
        - Recommendation: Low irrigation needed
    
    [Example 3] Low moisture, high temperature
        - Soil: 20%, Temp: 40°C, Humidity: 30%
        - PREDICTED: ~57 minutes
        - Recommendation: Very high irrigation needed
    
    [Example 4] Optimal conditions
        - Soil: 60%, Temp: 25°C, Humidity: 55%
        - PREDICTED: ~20 minutes
        - Recommendation: Moderate irrigation

⏱️ Time: 5-10 seconds


================================================================================
4. UNDERSTANDING THE OUTPUT (TASTING)
================================================================================

What do the numbers mean?
-------------------------

SOIL MOISTURE (0-100%):
    0-30% = Very dry soil → More irrigation needed
    31-60% = Moderate moisture → Medium irrigation
    61-100% = Wet soil → Less irrigation needed

TEMPERATURE (10-45°C):
    Higher temperature = More water evaporation → More irrigation needed
    Lower temperature = Less evaporation → Less irrigation needed

HUMIDITY (20-90%):
    Low humidity = Dry air → More irrigation needed
    High humidity = Moist air → Less irrigation needed

CROP TYPE:
    0 = Wheat
    1 = Corn
    2 = Rice
    (Different crops have different water needs)

IRRIGATION DURATION (0-60 minutes):
    0-15 min = Low irrigation
    16-30 min = Moderate irrigation
    31-45 min = High irrigation
    46-60 min = Very high irrigation


Model Performance Metrics:
---------------------------
R² Score: 0.93 (93%)
    → This means the model is 93% accurate in predicting irrigation needs

RMSE: ~4 minutes
    → On average, predictions are within 4 minutes of the actual value

MAE: ~3 minutes
    → The typical error is about 3 minutes

5. TROUBLESHOOTING (FIXING COMMON ISSUES)
================================================================================

PROBLEM 1: "python is not recognized"
--------------------------------------
SOLUTION:
    ✓ Try using 'python3' instead of 'python'
    ✓ Reinstall Python and check "Add to PATH" during installation


PROBLEM 2: "No module named 'tensorflow'"
------------------------------------------
SOLUTION:
    ✓ Make sure you ran: pip install tensorflow pandas numpy scikit-learn joblib
    ✓ Try: pip3 install tensorflow pandas numpy scikit-learn joblib
    ✓ Check if it's installed: pip list | grep tensorflow


PROBLEM 3: "Permission denied" errors
--------------------------------------
SOLUTION:
    ✓ Windows: Run Command Prompt as Administrator
    ✓ Mac/Linux: Use: pip install --user [package names]


PROBLEM 4: Training is very slow
---------------------------------
SOLUTION:
    ✓ This is normal on older computers
    ✓ Wait patiently (it should complete in under 2 minutes)
    ✓ Close other programs to free up RAM


PROBLEM 5: "irrigation_dataset.csv not found"
----------------------------------------------
SOLUTION:
    ✓ Make sure you ran Step 1 first (python data_generator.py)
    ✓ Check that the file was created in the same folder
    ✓ Run all commands in the same folder


PROBLEM 6: "irrigation_model.keras not found"
----------------------------------------------
SOLUTION:
    ✓ Make sure you ran Step 2 first (python train.py)
    ✓ Wait for training to complete (don't interrupt it)
    ✓ Check that both .keras and .pkl files were created
