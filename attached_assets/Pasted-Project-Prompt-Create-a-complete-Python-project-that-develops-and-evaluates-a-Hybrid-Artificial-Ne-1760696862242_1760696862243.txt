Project Prompt:

Create a complete Python project that develops and evaluates a Hybrid Artificial Neural Network (ANN) to optimize agricultural irrigation and reduce water wastage.

The project should be structured into separate, well-commented Python files. The core of the project is to design a novel hybrid activation function and use it within an ANN model that predicts the optimal irrigation time for a field.

Here are the detailed requirements:

1. Project Goal: To predict the "required irrigation duration" (in minutes) based on real-time environmental data. This prediction will help farmers avoid overwatering and underwatering, thus conserving water.

2. Dataset:

Generate a synthetic dataset using NumPy and Pandas. The dataset should contain 1000 samples.

The dataset needs the following input features (independent variables):

soil_moisture (percentage, 0-100)

temperature (°C, 10-45)

humidity (percentage, 20-90)

crop_type (categorical: 0 for Wheat, 1 for Corn, 2 for Rice)

The dataset needs one target variable (dependent variable):

irrigation_duration_minutes (0-60 minutes). This should be calculated based on a logical formula, for example: duration = 60 - (soil_moisture * 0.5) + (temperature * 0.3) - (humidity * 0.2). Add some random noise to make it realistic.

Save this dataset as irrigation_dataset.csv.

3. The Hybrid Activation Function:

Create a custom activation function named "Hybrid_Swish_ReLU".

This function should combine the properties of the Swish and Leaky ReLU functions.

The logic should be:

If x > 0, it behaves like Swish: f(x) = x * sigmoid(x)

If x <= 0, it behaves like Leaky ReLU: f(x) = 0.01 * x

Implement this function using TensorFlow/Keras backend functions so it can be used in a Keras model.

4. The ANN Model:

Use TensorFlow and Keras to build the regression model.

The model architecture should be a Sequential model with:

An input layer appropriate for the 4 features.

Two hidden layers, each with 64 neurons.

Crucially, use the custom Hybrid_Swish_ReLU activation function in both hidden layers.

An output layer with a single neuron (for the irrigation_duration_minutes prediction) and a ReLU activation function to ensure the output is non-negative.

Compile the model using the Adam optimizer and Mean Squared Error (MSE) as the loss function.

5. Project Structure & Files: Please generate the following Python files:

a) data_generator.py:

Contains the code to generate the synthetic irrigation_dataset.csv.

b) model.py:

Defines the custom Hybrid_Swish_ReLU activation function.

Defines the function create_model() which builds and compiles the Keras ANN model as described above.

c) train.py:

Imports functions from model.py.

Loads the irrigation_dataset.csv using Pandas.

Splits the data into training (80%) and testing (20%) sets.

Scales the features using StandardScaler from scikit-learn.

Creates the model by calling create_model().

Trains the model on the training data for 50 epochs.

Evaluates the model on the test data and prints the Mean Squared Error.

Saves the trained model to a file named irrigation_model.h5.

d) predict.py:

Loads the saved model irrigation_model.h5.

Loads the StandardScaler used during training (you'll need to save it in train.py using joblib).

Includes a function predict_irrigation(soil_moisture, temperature, humidity, crop_type) that takes new data, scales it, and returns a predicted irrigation duration.

Provides an example of how to use this function (e.g., predict for soil_moisture=35, temperature=30, humidity=60, crop_type=1).

e) requirements.txt:

A file listing the necessary Python libraries: tensorflow, pandas, numpy, scikit-learn, joblib.

Provide the complete source code for all these files.
